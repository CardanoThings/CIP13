# Security Policy

## Supported versions

This repository is a static documentation site for CIP-13 / `web+cardano` links.
Security fixes apply to the latest `main` branch only.

## Reporting a vulnerability

If you find a security issue in this site (for example XSS in rendered content,
dependency risk that affects the published pages, or exposure of secrets in the
repo), please report it **privately**:

1. Prefer [GitHub Security Advisories](https://github.com/CardanoThings/CIP13/security/advisories/new) if available for this repository
2. Otherwise contact a repository maintainer privately via GitHub

Please do not open a public issue for security vulnerabilities.

## Out of scope

Design and specification of Cardano Improvement Proposals themselves belong in
the [cardano-foundation/CIPs](https://github.com/cardano-foundation/CIPs)
repository, not here.
